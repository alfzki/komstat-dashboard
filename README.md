# Dokumentasi Library, Framework, dan Plugin

## Frontend

### React
- **Deskripsi:** Library JavaScript untuk membangun antarmuka pengguna berbasis komponen.
- **Fungsi utama:** Membuat UI dinamis dan modular.
- **Dokumentasi:** https://react.dev/

### Material UI (MUI)
- **Deskripsi:** Framework UI berbasis React dengan komponen siap pakai dan sistem styling modern.
- **Fungsi utama:** Menyediakan komponen UI seperti tombol, tabel, form, chart, dsb.
- **Dokumentasi:** https://mui.com/

### MUI X (x-charts, x-data-grid, x-date-pickers, x-tree-view)
- **Deskripsi:** Komponen lanjutan untuk chart, data grid, date picker, dan tree view berbasis MUI.
- **Fungsi utama:** Visualisasi data, tabel interaktif, filter tanggal, dan navigasi pohon.
- **Dokumentasi:** https://mui.com/x/

### D3.js (d3-scale, d3-scale-chromatic)
- **Deskripsi:** Library visualisasi data untuk manipulasi DOM berbasis data dan pembuatan skala warna.
- **Fungsi utama:** Membuat chart, peta, dan visualisasi interaktif.
- **Dokumentasi:** https://d3js.org/

### Plotly.js
- **Deskripsi:** Library chart interaktif berbasis JavaScript.
- **Fungsi utama:** Membuat grafik interaktif seperti bar, line, scatter, dsb.
- **Dokumentasi:** https://plotly.com/javascript/

### html2pdf.js
- **Deskripsi:** Plugin untuk mengkonversi elemen HTML menjadi file PDF di browser.
- **Fungsi utama:** Export tampilan halaman menjadi PDF.
- **Dokumentasi:** https://github.com/eKoopmans/html2pdf.js

### React Router DOM
- **Deskripsi:** Library routing untuk aplikasi React.
- **Fungsi utama:** Navigasi antar halaman tanpa reload.
- **Dokumentasi:** https://reactrouter.com/

### React Simple Maps
- **Deskripsi:** Komponen React untuk visualisasi peta berbasis SVG.
- **Fungsi utama:** Menampilkan peta dunia/interaktif.
- **Dokumentasi:** https://www.react-simple-maps.io/

### Day.js
- **Deskripsi:** Library manipulasi tanggal ringan untuk JavaScript.
- **Fungsi utama:** Parsing, validasi, manipulasi, dan formatting tanggal.
- **Dokumentasi:** https://day.js.org/

## Backend (R)

### plumber
- **Deskripsi:** Framework untuk membuat REST API di R.
- **Fungsi utama:** Menyediakan endpoint API dari script R.
- **Dokumentasi:** https://www.rplumber.io/

### jsonlite
- **Deskripsi:** Library untuk parsing dan pembuatan data JSON di R.
- **Fungsi utama:** Membaca dan menulis file JSON.
- **Dokumentasi:** https://cran.r-project.org/web/packages/jsonlite/

### dplyr
- **Deskripsi:** Library grammar of data manipulation di R.
- **Fungsi utama:** Filter, agregasi, transformasi, dan manipulasi data.
- **Dokumentasi:** https://dplyr.tidyverse.org/

### readr
- **Deskripsi:** Library untuk membaca file CSV/TSV/tabular di R.
- **Fungsi utama:** Import data tabular ke R dengan cepat.
- **Dokumentasi:** https://readr.tidyverse.org/
